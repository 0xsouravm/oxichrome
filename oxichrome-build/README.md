# oxichrome-build

Reads the metadata oxichrome's macros embed in the compiled WASM and generates the build artifacts (manifest.json, JS shims, HTML shells) for oxichrome.

This is an internal crate. You probably want [oxichrome](https://crates.io/crates/oxichrome) or [cargo-oxichrome](https://crates.io/crates/cargo-oxichrome) instead.
